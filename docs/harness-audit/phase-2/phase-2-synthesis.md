# Phase 2 — RTM & Input-Domain Adversarial-Fixture Audit (Synthesis)

Two-way requirements traceability + fixture benign/adversarial catalog + hostile-input EP/BVA/FMEA coverage matrix. FIND-AND-DOCUMENT only — no product/test code changed.

## Headline

- **RTM: 87 user-facing capabilities** — none=**0**, happy-path-only=**68**, has-negative/boundary=**18**, strong-with-visual-oracle=**1**.
  - **Central finding:** every feature has a test; the gap is oracle *strength*, not test *existence*. Only 1/87 capabilities carry a strong visual/artifact oracle. This is Phase-1's weak-oracle result localized onto exactly the visual + security-enforcement features a user/attacker would notice.
- **Fixtures: 200** — 98 benign / 102 adversarial; 32 orphan (consumed by no test), 1 referenced-but-missing. Prior on-disk inventory ~60% stale (PRIOR coverage_inventory.json enumerates 81 fixtures (root + image_pdf/ + realwo...).
- **Hostile-input classes: 38** — 28 nonzero, 6 partial, **4 zero-coverage**.

## Zero-coverage hostile-input classes (ranked by risk)

- **sheared / skewed CTM in content-stream**
- **0-page document (empty page tree)**
- **10k-page document (upper scale boundary)**
- **combining marks / ZWJ / grapheme clusters**

## Top uncovered / weakly-covered user-visible capabilities

1. **[High] Redaction — true content removal (confidentiality)** (coverage=strong-with-visual-oracle-but-conditionally-skipped) — The only oracles that prove the secret is gone from the saved decompressed stream (completeness:67, image_redaction_phase7:428) GTEST_SKIP under fixture fallback; verifier.checkTextRemoved is never asserted FALSE. A redaction that paints a box but leaves Tj operators intact can ship GREEN — a data-disclosure defect.
2. **[High] Malformed-PDF sandbox / CVE neutralization** (coverage=has-negative-or-boundary (no-throw-only oracle)) — cve_replay: 21 CVE replays with 1 timing assertion around a catch-all try/catch; ProcessSpawnAttemptBlocked / GoToRRemotePathRejected / DataUriNotExecuted assert only no-throw. A regression re-enabling NTLM leak / /AA JS exec / font PostScript / SSRF ships green — none asserts the attack was neutralized.
3. **[High] Signature trust-chain + tamper detection + LTV forged-GOOD** (coverage=has-negative-or-boundary (weak/broken negatives)) — Cert trust is never positively validated (self-signed satisfies every predicate); the tamper test has an operator-precedence bug that may write a no-op; no test rejects a GOOD OCSP from an untrusted responder. A signature from an attacker-controlled issuer is indistinguishable from a trusted one.
4. **[High] Edit existing text — visual correctness** (coverage=has-negative-or-boundary (extraction-only oracle)) — The edit path is visual but oracles are extraction-present; mirror/invisible/white/wrong-glyph/wrong-position edits and neighbour-span clobbering (the shipped ambient-state-leak class) all pass. MultiplePageEdits has zero assertions; the adversarial-ambient corpus test is SUCCEED()-only.
5. **[High] Text alignment (Left/Center/Right/Justify)** (coverage=happy-path-only (visual feature, no geometry oracle)) — Every alignment test uses extractPlainText().find(); position/x-offset is never asserted — text drawn left when Center/Right requested passes. Justify has a substring bug making fully un-justified output pass.
6. **[High] TRE scanned-text reconstruction — visual correctness** (coverage=happy-path-only (visual, no render/re-extract oracle)) — Reconstruction writes new glyphs into the content stream but nothing renders/re-extracts the output; the 'critical' Y-flip coord-mapper tests are tautological (never call the product mapper). Wrong/garbled/mirrored/off-page reconstructed text ships green.
7. **[High] Image resize / rotate / crop (CTM)** (coverage=has-negative-or-boundary (no-op indistinguishable)) — Success is asserted via return bool / non-null display list; a wrong CTM producing a mirrored or HALF-SIZE image (a bug class this subsystem has repeatedly hit) is indistinguishable from correct. Only image_ctm_leak/mediabox_origin_crop pin geometry.
8. **[High] Autosave / crash-recovery capture** (coverage=happy-path-only (assertion-free probe)) — autosave_capture_audit (15 edit families) is SUCCEED()-only with ZERO EXPECT/ASSERT — finishRow() records capture_present=NO as passing data. A crash-recovery regression that drops all edits produces a green suite (the exact data-loss class this project keeps shipping).
9. **[High] Full-text search — non-empty result correctness** (coverage=happy-path-only (tautological oracle)) — BasicSearch/SearchPage_FindsText assert totalMatches()>=0 (a tautology); quad/hit checks are in loops that run zero times when empty. Broken indexing returning zero hits for text actually on the page is invisible.
10. **[High] OCR recognition quality** (coverage=happy-path-only) — OcrOnScannedPdf asserts hocr non-empty + blocks>0; gibberish recognition passes because no known word from the fixture is checked. RenderPageAt300Dpi accepts >100px so a DPI regression silently degrades OCR input.
11. **[Med] Permission enforcement — residual (re-encryption path / new downstream consumers)** (coverage=has-negative-or-boundary (main surface covered; residual narrow)) — CORRECTED (karen phase-2 gate): the main copy/print restriction surface IS enforced by real behavioral tests in test_permission_enforcement.cpp (engine + UI refusal, mutation-killable). Residual gap is narrow: test_encryption_roundtrip.cpp::CopyFalsePermissionEnforcedOnReopen is flag-read-only, and saveEncrypted's re-encryption path / future downstream consumers ignoring PermissionFlags have no enforcement test. Re-scoped from High to Med; not a rewrite-existing-tests item.
12. **[Med] Optimize — deleted-content leak** (coverage=happy-path-only) — OptimizeDoesNotLeakDeletedFormFieldValues asserts only pageCount>0 after reopen — the named leak (stale/deleted form-field values remaining embedded after garbage=4) ships green.

## Cross-validation with Phase-1

- RTM none=0 + strong_visual=1 corroborates Phase-1 (147/402 files weak-oracle); the weakness is concentrated on visual + security-enforcement features.
- Fixture danger-zones (paths fed ONLY benign inputs: OCR/TRE, scanned-render, PDF/A tagging, save/rewrite) match the hostile-input PARTIAL/ZERO classes and the RTM happy-path-only rows.
- Sheared/skewed-CTM = ZERO fixture coverage is the direct untested sibling of the -100 Tz mirror bug this audit exists for; the adversarial-ambient corpus has half-SCALE cm but no shear.
- flaw_corpus (47 adversarial fixtures) all feed ONE open-only smoke test -> adversarial breadth exists but adversarial DEPTH per product-path is thin (an open-parse pass is not a save/redact/render pass).
