# PDFE v0.5.5

A release over v0.5.4 with image-editing improvements and bug fixes. It covers
image editing (moving, sizing and cropping images, including on scanned pages,
and a new Image menu command), the Delete key, form fields, push-button
rendering and the memory used by whole-page renders.

## Images

- **You see the image itself while you move, resize or rotate it,** at its
  current angle, crop and flip, instead of an empty outline.
- **Images stay on their page.** A drag keeps the image's centre on the page.
  The part that hangs off the paper is shaded red, and its tooltip says it will
  be cropped when you save.
- **Saving crops images where they hang off their page.** Save, Save As, the
  redaction save and the save before signing cut each overflowing image to the
  page; the crop is undoable, and images already on the page are saved
  byte-identical. Signed documents and autosave are not cropped.
- **The page box is the MediaBox (the paper), not the CropBox.** After you crop
  a page with the Crop tool, an image that reaches past the crop but stays on
  the paper is no longer cut on save, so the page crop stays reversible.
- **A click on a scanned page no longer picks up the scan.** On a page that is
  one full-page image, a click or drag outside the image you are working on
  used to select the scan and move, resize or rotate the whole page. An image
  covering 90% or more of the page is now treated as the page background: a
  single click deselects instead.
- **Selecting a page-covering image on purpose:** double-click it with the
  Image Tool, or use **Image > Select Page Background Image**. Once selected it
  moves, resizes, rotates and deletes like any other image.
- Image actions now act on the image tool's own page, not on whatever page has
  scrolled into view.

## Delete key

- **Del deletes what is selected before it deletes pages.** With an image,
  annotation, text box or form field selected, or while typing in a field or
  editing text, Del now acts on that, as it should. Before, Del always asked to
  delete the page. With nothing selected, Del still deletes the selected pages
  after the confirmation, as before.
- **Pages > Delete** no longer greys out while you are editing text, and the
  Image Tool no longer swallows Page Down and the other navigation keys.

## Form fields

- **A placed form field can be clicked and typed into while the form tool is
  still selected,** instead of a click placing another field on top of it.
- **Push-button fields render their background again** (GitHub #465). The
  bundled MuPDF dropped the size of the push-button fill, so push buttons
  showed a blank interior. This was the known issue listed in v0.5.4; it is
  fixed.

## Rendering memory

- **Whole-page renders use half the memory.** Printing, export, compare, diff
  and text recognition render a whole page at a time. They used to hold the
  page image twice at once; now they hold it once. On a 200 x 200 inch drawing
  sheet at double resolution that is about 3.3 GB instead of about 6.2 GB. When
  there is not enough memory, the render now returns an empty image instead of
  crashing.

## Known issues

- **An intermittent crash in a tile-rendering test** (GitHub #469). It was seen
  once in the automated test suite and has not been reproduced on demand; no
  user report is linked to it. Tracked for investigation.

## Checksums

their SHA-256 values, and each has a `.sha256` file beside it. The Windows
files are added to this release separately.
