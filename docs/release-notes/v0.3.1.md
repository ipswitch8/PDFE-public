# PDFE v0.3.1

A performance maintenance release. It removes a thumbnail-panel-induced stall
that made the main view's zoom slow to respond — and appear to hang — after
opening a large PDF and scrolling through many pages in the thumbnail panel.
No new features and no API or on-disk format changes; a drop-in update over
v0.3.0.

## Changes

- **Thumbnails now render off the UI thread.** The page-thumbnail panel used to
  rasterize full pages synchronously on the Qt UI thread and requested a
  thumbnail for *every* page as soon as a document opened. On a large document
  that flooded the event loop, so the main canvas's zoom repaint queued behind
  the backlog — slow on the first zoom, then apparently hung. Thumbnail
  rasterization now runs on a dedicated worker pool with per-thread rendering
  contexts, mirroring the main canvas's tile renderer. (`7ebfbfc7`, `6fcc8b39`)
- **Thumbnails load lazily by viewport.** The panel now requests thumbnails only
  for the pages near the visible range (plus a small prefetch margin), extends
  the window as you scroll, and cancels work for pages scrolled far off-screen,
  instead of eagerly rendering all pages up front. (`67dd2c65`)
- **Stale-zoom tiles are evicted on a zoom change.** A zoom change produces an
  entirely new set of tile keys; the prior zoom's tiles are now dropped from the
  tile cache instead of lingering and churning its LRU against the newly
  requested tiles. (`6fc0e349`)
- Added regression tests pinning each of the above, including a large-document
  scroll-then-zoom integration guard. (`ed702daa`)
