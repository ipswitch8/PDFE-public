# PDFE v0.5.1

A signature-and-image bug-fix release over v0.5.0, rolling up the
sign-bugs-2026-11 batch: five user-reported defects plus six sibling defects
found while sweeping the same functions. No on-disk format changes; a
drop-in update.

## Signing

- **The Form tool's signature field actually signs now.** Placing a signature
  field left the tool stuck in creation mode, so the red SIGN placeholder
  never responded to clicks — the earlier activation fix (GitHub #328) was
  unreachable in the real flow. The tool now returns to interaction mode
  after placing a field, a re-click on the selected field re-opens the
  signing flow, and a failed signing attempt reports in the status bar.
  (`e5050ee7`, GitHub #369)
- **The signature can be sized and placed.** The Sign dialog gains a Field
  Placement group (page, X, Y, width, height); previously the field rect was
  hard-coded. (`e5050ee7`, GitHub #370)
- **Saved signature images remember their certificate.** A library image now
  stores the PFX file path it was used with and restores it on reselect (the
  passphrase is never stored). (`e5050ee7`, GitHub #371)
- **No more crash after a wrong-passphrase error.** Signing error paths now
  rebuild the renderer and canvas exactly like the success path, closing a
  use-after-free reintroduced through the error door, and a failed sign
  rolls back cleanly without leaving a stray SIGN field. (`e5050ee7`,
  GitHub #372)
- **Signing with a saved library image works.** The temporary image file no
  longer disappears before the signer reads it. (`ebc219ef`, GitHub #374)
- **The Signatures panel signs the field you clicked**, not the first
  unsigned field in the document. (`ebc219ef`, GitHub #375)
- **Side panels stay bound to the live document across a sign**, fixing a
  latent crash on the next panel refresh after signing. (`ebc219ef`,
  GitHub #379)

## Images

- **Inserted images: handles land on the image and dragging is no longer
  inverted.** The image subsystem mixed three coordinate conventions with no
  vertical flip anywhere; it now converts exactly once at each boundary, so
  selection handles coincide with the rendered image and a downward drag
  moves the image down at commit. (`8bfef6b8`, GitHub #373)
- **Rotation drag direction corrected** — the previous sign convention was
  derived against synthetic test coordinates and was inverted for real mouse
  input. (`8bfef6b8`, GitHub #376)

## Test fidelity

- Two test seams that structurally masked the above defect classes were
  fixed in lockstep: the UI click pipe no longer force-resets the Form tool
  (GitHub #377) and the canvas coordinate seams carry documented space
  contracts instead of self-cancelling (GitHub #378). (`8bfef6b8`,
  `ebc219ef`)
