# PDFE v0.4.0

A feature-and-fix release that resolves five user-reported UI defects — two of
them previously-missing capabilities, which is why this is a minor bump over
v0.3.2 rather than a patch. Supersedes v0.3.2; a drop-in update (no API or
on-disk format changes).

## Changes

- **Cross-document page drag-and-drop** — you can now drag a page from one open
  document's Pages panel into a different open document's window; the page is
  copied in via an undoable command. Previously this did nothing (never
  implemented). (GitHub #325, `cfe3cb94`)
- **Page reorder within a document now persists** — dragging a thumbnail to
  reorder actually changes the document's page order, re-renders the canvas, and
  marks the document dirty. Previously the thumbnail moved but the page order was
  untouched (the icon-mode list used a `Snap` movement that pre-empted the drop
  handler). (GitHub #326, `cfe3cb94`)
- **Sign Document can use an image of your signature** — the Sign dialog now has
  an image picker, and the chosen image is embedded as the visible signature
  appearance. Previously only the generated text/logo appearance was possible.
  (GitHub #327, `68193922`)
- **Form-tool signature fields are now clickable** — clicking a signature field
  placed with the Form tool opens the signing flow and signs that field.
  Previously the red "SIGN" field was placed but clicking it did nothing.
  (GitHub #328, `68193922`)
- **Inserted images are selected automatically** — after Insert Image, the image
  is selected so its move/resize/rotate/crop handles are live immediately, with
  no extra click. Previously the handles only appeared after separately clicking
  the image. (GitHub #329, `54025ccb`)

Each fix ships with regression coverage at the real surface (model/command
GoogleTests, MainWindow-level event tests, and pywinauto UI tests). Full detail:
`docs/audit/ui-defects-2026-11/CLOSING.md`.
