# PDFE v0.4.1

A small UI fix-and-polish release over v0.4.0. No API or on-disk format changes;
a drop-in update.

## Changes

- **"Report an issue" now points at the right place.** The in-app report link
  opened an issue tracker external users couldn't reach; it now opens the public
  project's issue tracker. Reporting is also now a choice: **Report on GitHub**
  or **Report by Email** (to `pdfe@itwerx.net`). (`8b543a98`)
- **Opening a file from a network location is no longer a dead end.** When PDFE is
  set to open local files only, trying to open a file on a network (UNC) path now
  shows a dialog that explains the behavior is controlled in Preferences and
  offers an **"Allow this"** button — one click allows network opens and opens the
  file, with no trip through Preferences. (`25d17e0d`)

Full detail: `docs/audit/ui-report-netopen-2026-11/CLOSING.md`. Supersedes v0.4.0.
