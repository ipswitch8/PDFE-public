# PDFE v0.4.2

A small UI bug-fix release over v0.4.1. No API or on-disk format changes; a
drop-in update.

## Changes

- **Rearranging pages within a document works again.** Dragging a page thumbnail
  to a new position within the same document now shows a drop-position indicator
  and actually reorders the pages. (Previously the thumbnail dragged but the drop
  had no effect — the within-document path had been shadowed by the
  cross-document drag feature.) (`3712145b`, GitHub #333)
- **Editing text after rotating a page now reads the right text.** When a page is
  rotated and text is then edited, the editor is populated from the page's
  post-rotation layout instead of the pre-rotation layout. (Rotation now
  invalidates the text-extraction caches, not just the rendered tiles.)
  (`874502c1`, GitHub #334)

Full detail: `docs/audit/ui-reorder-rotate-2026-11-closing.md`. Supersedes v0.4.1.
