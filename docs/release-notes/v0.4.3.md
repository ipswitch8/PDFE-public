# PDFE v0.4.3

A small UI bug-fix / test-hardening release over v0.4.2. No API or on-disk
format changes; a drop-in update.

## Changes

- **"Report an Issue → Report by Email" no longer dead-ends.** On a machine with
  no mail client registered for `mailto:` links, choosing Report by Email used to
  leave the user at the OS "You'll need a new app to open this mailto" error with
  no way to reach the support address. It now detects that the mail client could
  not be opened and shows a fallback dialog displaying `pdfe@itwerx.net` with a
  **Copy email address** button. (`6e073f65`, GitHub #337)
- **Page-reorder and delete test coverage hardened.** Two UI regression tests that
  looked like they exercised a page drag-reorder and a right-click delete actually
  asserted too little — a reorder that changed nothing, or a delete that left a
  stale thumbnail, could still have passed. The reorder test now asserts the real
  resulting page order and the delete test now drives the real context-menu signal
  path and asserts the thumbnail cache is refreshed. No user-facing behaviour
  change; these close latent gaps that could have let a real regression through.
  (`b9a6027b`, GitHub #338, #339)

Full detail: `docs/audit/ui-followups-337-335-closing.md`. Supersedes v0.4.2.
