# PDFE v0.5.2

A UI bug-fix release over v0.5.1, rolling up the ui-bugs-381-383 batch: the
three product regressions the v0.5.1 post-release sweep surfaced. No on-disk
format changes; a drop-in update.

## Fixes

- **File Attachment and Stamp tools are reachable again, and attaching a file
  no longer crashes.** On any profile with a saved toolbar layout the Stamp and
  File-Attachment actions were dropped from the annotation toolbar (they were
  missing from the toolbar-action registry), and the attachment-create flow
  could crash after the file/icon dialogs. Both actions are registered now, and
  the create flow is hardened against a use-after-free when the window closes
  mid-dialog. (`e56e4ade`, GitHub #381)
- **Three UI regressions corrected.** The "Cannot Open Document" error for an
  unreachable network path again names it as a network **(UNC)** location in the
  main message; the annotation undo-after-delete and status-bar form-field-count
  behaviours are verified correct and their tests brought back in line with the
  real behaviour. (`2fc0c14d`, GitHub #382)
- **Wrong signing-passphrase feedback is reliable.** A wrong PFX passphrase has
  always raised a visible "Signing Error" dialog; a test-side timing issue made
  it look otherwise. The signing-error path now has a dedicated regression test
  that also confirms the message never discloses the passphrase or key path.
  (`c873e069`, GitHub #383)

Closeout and verification record: `docs/audit/ui-bugs-381-383-closeout.md`
(`714b6475`).
