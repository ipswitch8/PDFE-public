# ---------------------------------------------------------------------------
# PDFE Cross-Platform CORE PARITY SUITE  (register class C-10, phase-5)
#
# The named set of platform-INDEPENDENT, behavioral-core GoogleTest suites that
# MUST pass IDENTICALLY on Windows, Linux, and macOS. This file is the SINGLE
# SOURCE OF TRUTH for the selection: tools/gate/parity_filter.py reads it and
# emits a ':'-joined gtest_filter string, and all three validation lanes
# (windows-/linux-/macos-validation.yml) invoke that same script, so the
# selection is byte-identical on every platform by construction.
#
# INCLUSION CRITERION: the document/model behavioral core that must not diverge
# across OSes -- open/parse, save-routing, redaction confidentiality, text
# extraction, page ops, content-stream editing, coordinate transforms,
# encryption/permissions, forms/metadata round-trips, font parsing/substitution,
# undo/redo, PDF/A + optimize, and the generative/format-compat invariants.
#
# DELIBERATELY EXCLUDED (platform-DIVERGENT or platform-SPECIFIC, so NOT parity):
#   * Qt widget/UI suites (*Dialog*, *Panel*, MainWindow*, *ToolBar*, PdfCanvas*,
#     Menu*, TabOrder*, Keyboard*, Theme*, *Icon*, A11y*, Accessibility*) -- UIA
#     tree / pixel differences are legitimately per-platform (pywinauto layer).
#   * Windows-only endurance / handle / process suites (DllDependencyTest,
#     ProcessMitigationsTest, EnduranceLeakTest, OpenCloseLeakCycleTest,
#     SingleInstanceGuard, InstallerResidue, CrashHandlerTest) -- GDI handles /
#     Win32 mitigations do not exist on Linux/macOS.
#   * Pixel-render fidelity / HiDPI (RenderFidelityTest, HiDPIRender, HiDPITest,
#     *LcdSubpixel, *PerceptualAlpha) -- font rasterization differs per platform.
#   * The PreflightOpen.* / PreflightXPlatform.* sandbox suites -- these are
#     platform-DIVERGENT BY DESIGN (GetModuleFileNameW vs /proc/self/exe vs
#     _NSGetExecutablePath, fork/waitpid vs CreateProcess). Each lane already
#     runs them against its own OS branch; parity is the wrong axis for them.
#   * Performance/benchmark suites (Perf*, XfaSaveBenchmark, *Performance) --
#     wall-clock is machine-dependent; guarded by the C-07 perf floor instead.
#   * Live-network suites (*Live, TsaRealEndpointTest) -- non-hermetic.
#
# FORMAT: one gtest_filter pattern per line (suite name, trailing '.*' optional
# -- parity_filter.py normalizes). '#' comments and blank lines are ignored.
# Keep this list APPEND-mostly; removing a suite weakens the parity contract.
# ---------------------------------------------------------------------------
